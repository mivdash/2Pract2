# depviz

Программа показывает, от каких пакетов зависит NuGet-пакет (.NET).
Зависимости берутся напрямую из репозитория, без `dotnet` и `nuget`.
Практическая работа №2, вариант 7.

**Этап 1:** читает файл настроек и проверяет его. При ошибке пишет
`Ошибка: ...` и завершается с кодом 1.

**Этап 2:** берёт пакет из `package_name` и печатает его прямые зависимости.
Данные скачиваются из NuGet по адресу `repository` встроенными средствами
Python. Берётся последняя стабильная версия пакета, зависимости для разных
платформ объединяются. Режим `test_mode: true` появится на этапе 3.

## Настройки

Файл `nastroyki.yaml`, нужны все шесть настроек:

```yaml
package_name: Newtonsoft.Json                    # какой пакет смотрим
repository: https://api.nuget.org/v3/index.json  # адрес репозитория или файл
test_mode: false                                 # true: данные из файла
output_image: graph.png                          # имя картинки с графом
ascii_tree: true                                 # true: вывод деревом из символов
filter_substring: ""                             # пакеты с этим словом пропускаем
```

## Функции

- `prochitat_yaml`: превращает файл настроек в словарь
- `proverit_nalichie_klyuchey`: проверяет, что не забыта ни одна настройка
- `vzyat_stroku`: достаёт текстовую настройку и проверяет её
- `vzyat_da_net`: достаёт настройку true/false и проверяет её
- `check_repository`: проверяет, что `repository` указан правильно
- `zagruzit_nastroyki`: собирает проверенные настройки из файла
- `sozdat_razborshchik`: учит программу понимать команду пользователя
- `zagruzit_paket`: берёт пакет из настоящего репозитория nuget
- `napechatat_zavisimosti`: показывает прямые зависимости пакета
- `main`: запускает программу и сообщает, чем всё закончилось
- `razobrat_otvet`: превращает ответ сервера в json (он приходит сжатым)
- `skachat_json`: скачивает json по адресу, сбои сети делает понятной ошибкой
- `nayti_adres_reestra`: ищет адрес данных о версиях пакетов
- `adres_paketa`: собирает адрес документа пакета
- `sobrat_versii`: собирает версии пакета со всех страниц
- `vybrat_poslednyuyu`: берёт последнюю стабильную версию
- `pryamye_zavisimosti`: собирает зависимости версии
- `poluchit_paket`: находит пакет и возвращает версию и зависимости

## Запуск и тесты

```
py -m pip install -r requirements.txt
run.bat
run.bat moi_nastroyki.yaml
py -m pytest -v
```

## Примеры

Имена и версии условные:

```
> run.bat
Пакет: Demo.Pkg 2.0.0
Прямые зависимости: 2
  Dep.One [1.0.0, )
  Dep.Two [2.1.0, 3.0.0)

> run.bat net_takogo_fayla.yaml
Ошибка: Файл конфигурации не найден: net_takogo_fayla.yaml
```

`[1.0.0, )` значит «версия 1.0.0 и выше».
